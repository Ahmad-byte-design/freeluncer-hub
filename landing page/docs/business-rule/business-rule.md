# Veloce Motors – Business Rules

## 1. Overview
Veloce Motors is a premium car showroom landing page that promotes luxury and performance vehicles and captures customer interest through a test-drive form. The page must present the brand as high-end, trustworthy, and modern.

## 2. Business Objective
The main goal of this landing page is to:
- increase vehicle inquiries,
- generate test-drive bookings,
- build trust in the brand,
- highlight premium inventory and financing options,
- support both English and Arabic users.

## 3. Target Audience
- Car buyers seeking premium or performance vehicles
- Customers looking for luxury, certified cars
- Individuals interested in financing or flexible purchase options
- Local and international buyers

## 4. Brand Rules
- Brand name must always appear as: "Veloce Motors"
- The visual tone must feel premium, polished, and trustworthy
- The landing page should use a luxury automotive aesthetic with dark tones, premium spacing, strong typography, and modern card layouts
- The page must support both English and Arabic language modes

## 5. Content Rules
### 5.1 Header
- Must include:
  - logo
  - navigation links: Home, Cars, Why Us, Reviews, Contact
  - language switcher (EN / ع)
  - primary CTA: "Test Drive"

### 5.2 Hero Section
- Must communicate premium showroom positioning
- Must include:
  - key headline
  - short supporting description
  - primary CTA: "Browse Inventory"
  - secondary CTA: "Book A Test Drive"
  - stat cards showing trust metrics

### 5.3 Inventory Section
- Must display featured vehicles with:
  - image
  - brand
  - model name
  - specs
  - price
  - "View Details" CTA
- Each vehicle must appear as a premium card with consistent layout
- Inventory must feel curated, not random
- Price and vehicle names must remain readable and visually prioritized

### 5.4 Why Us Section
- Must explain the business advantages:
  - certified vehicles
  - transparent pricing
  - flexible financing
  - insured delivery
- Messaging must reinforce honesty, trust, and convenience

### 5.5 Reviews Section
- Must include customer testimonials with names and location
- Testimonials must sound authentic and credible
- Reviews should support the premium positioning and buyer confidence

### 5.6 Contact / Test Drive Section
- Must include:
  - contact details
  - booking form
  - date field
  - full name
  - email
  - phone number
- The form is used to qualify leads and book test drives

## 6. Functional Rules
### 6.1 Language Switching
- The page supports English and Arabic
- The language toggle must update:
  - text content
  - aria labels
  - page title metadata
  - relevant elements with Arabic translations
- Arabic layout should feel natural and readable
- RTL layout must be supported for Arabic

### 6.2 Navigation
- Navigation links must scroll to the correct sections
- Header must remain usable on mobile
- Mobile menu must open and close correctly
- Skip link must remain available for accessibility

### 6.3 Form Rules
- Form must prevent page reload on submit
- User must complete required fields before submission
- Form should validate:
  - full name is required
  - email format must be valid
  - phone number is required
  - preferred date is required
- On success: show a confirmation message
- On invalid input: show a relevant error message

### 6.4 Call-to-Action Rules
- The “Test Drive” CTA must lead users to the booking form
- CTA buttons must be visible, high-contrast, and clickable
- All CTAs must work consistently across desktop and mobile

## 7. Trust and Compliance Rules
- The website must avoid misleading claims
- All prices and promotions must be clearly presented
- Any warranties and inspections must be truthful and explainable
- Do not use unrealistic marketing language that creates false expectations
- Customer data from the form must be treated as confidential business lead data

## 8. UX Rules
- The landing page must be mobile responsive
- The content hierarchy must be clear and easy to scan
- Visual spacing must remain consistent across sections
- Buttons, links, and inputs must have clear hover, focus, and active states
- The page must support keyboard navigation
- Form and page elements must have accessible labels and status messages

## 9. Accessibility Rules
- Must support keyboard-only navigation
- Focus states must be visible
- Buttons and links must have descriptive text
- Images must have alt text
- Form fields must have labels
- Live status messages must be announced properly
- Color contrast must meet accessibility standards

## 10. Performance Rules
- Page must load quickly
- Images must be compressed and optimized
- Only necessary scripts should be loaded
- Layout should remain stable during interaction

## 11. Success Criteria
The landing page is considered successful when:
- users can clearly understand the brand and value proposition,
- key CTAs work as expected,
- the page feels premium and trustworthy,
- the English and Arabic versions both function correctly,
- the test-drive form captures valid leads,
- the site is responsive and accessible on mobile and desktop.

## 12. Business Acceptance Checklist
- [ ] Brand and premium styling are clearly communicated
- [ ] Navigation works correctly in both languages
- [ ] Hero section includes strong value proposition
- [ ] Inventory cards are displayed consistently
- [ ] Why Us section explains the differentiators
- [ ] Testimonials increase trust
- [ ] Contact form validates user input
- [ ] Form success state is visible to the user
- [ ] Page is responsive across devices
- [ ] Arabic version works properly with RTL
- [ ] Accessibility standards are respected
