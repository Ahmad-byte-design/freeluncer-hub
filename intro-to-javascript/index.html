JavaScript from Zero

13 small tasks in 5 levels, from your first console.log to a working todo app. Each one checks your work as you go.

  1. Open a task. Read the Goal and Steps.
  2. Open that task's starter.js in your editor. Each step is a TODO.
  3. Save and refresh. The Checks panel turns green as you finish each step.
  4. Stuck? Read the red error in the console first. The Solution tab is the last resort.
